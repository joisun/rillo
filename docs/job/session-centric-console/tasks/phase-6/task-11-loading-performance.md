# 会话加载性能

用户批准此前“极致优化”讨论，要求开始推进。继续现有worktree，不提交、发布或替换已安装服务。

1. 接入Codex原生useStateDbOnly，目录与列表共享100条元数据、单次请求及有界短缓存。
2. 独立后台连接扫描修复，空索引先核验；通知/文件事件与低频轮询共同刷新。
3. 用户定位优先，预读不占满并发；离屏停止后续请求。
4. 只在能够证明历史未变时复用已完成时间索引，否则重新读取。
5. 添加有意义的回归，测量真实冷/热首屏、目录切换及正文读取，更新预览与相关文档。

验收不得以标题搜索替代正文搜索，不得新增持久正文库，分页不能因100条共享读取而漏项；后台失败不影响已有快速结果，冷空索引修复失败明确报错。
