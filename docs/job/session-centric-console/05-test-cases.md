# 验证用例

## task-11 性能增量

| 优先级 | 场景 | 预期 |
| --- | --- | --- |
| P0 | 根列表和目录同时请求100条 | 1次native快速查询，完整100条和原生cursor |
| P0 | 空索引有未入库日志/核验失败 | 核验后读到历史；失败报错，不显示空成功 |
| P0 | 日志重写、截断、回滚或snapshot失效 | 重读或409恢复，不能保留错误热点 |
| P1 | 同参数并发、过期、来源与筛选不同 | 单次查询、后台刷新、有界缓存、相互隔离 |
| P1 | 修复阻塞、热力预读占用、离屏 | 独立连接，用户优先且有保留位置，取消预读 |
| P1 | 加载后分页锚点离开屏幕 | 不沿用旧intersection多拉一页 |
| P1 | 原生300条分页、浏览器冷/热首屏 | 身份/排序/cursor一致，分别记录耗时 |
