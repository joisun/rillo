# 验证计划

直接影响：引用命名空间、幂等与单父级、原生/登记混合环、fork来源、真实执行区间、部分分页与按时间消息定位；分别使用临时SQLite和fake app-server验证。

间接影响：Scheduled启动、运行、恢复、设置、SSE、独立打包插件和API版本；沿用现有集成测试，验证旧Task链路不会再启动。

交互边界：hover定位真实消息、拖出行不换会话、键盘/触屏事件、节流与过期响应取消、滚动暂停及下次热力条操作自动恢复、视图切换保留状态、fork来源跳转、搜索浮层、自动分页和整页连接恢复。单元交互与Playwright headless合成会话、匿名原生截图结合；额外原生ID/时间比较不留正文。

非功能：不持久化正文、不改旧Task文件、原生查询有界、读历史不创建模型Turn、不触碰已安装43127服务。只读真实Codex验证仅输出计数/状态。文档扫描区分活跃指导和历史spec/job。
