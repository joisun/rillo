# 定时任务会话策略与压缩

用户已要求实施：创建和编辑任务支持新建、继承、自动；支持自定义或动态跟随本地自动压缩阈值；提供 compact HTTP/MCP 接口。

- 新建：每轮独立会话，现有任务保持此默认值。
- 继承：原生 resume 本任务上次兼容会话；无历史时新建。恢复已有会话失败时明确失败，不偷偷新建。
- 自动：首次新建，其后默认继承；本轮任务通过结果末尾的明确标记选择下一轮策略。失败结果不作为新策略。
- 阈值：Codex 原生 token 阈值；null 表示不覆盖本地配置。读取页面值不写本机配置。未配置时如实显示模型默认，不伪造数值。
- compact：沿用会话控制的串行、幂等回执；不把“已接受”当作完成；运行中的会话不主动打断。
- 用户追加：最大继承轮数默认20，可修改。首次新建不计入，实际继承达到上限后下一轮新建；自动模式继承也遵守上限。
- 用户追加：执行记录标明本轮实际 new/reuse、继承序号及换新原因。
- 用户要求验收直接使用 computer use，不继续 visual-driven-review 报告流程。已切换至 CUA 操作 Chrome 的隔离预览。

不修改用户任务、生产服务或持久 Codex 配置；保留已有工作区改动；不提交、不发布。

前述讨论及用户本次“先实现”指令授权实施，流程不新增配置开关或重复审批。
