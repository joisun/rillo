# 验证计划

- 来源隔离：provider/store_id/session_id 不可混用，浏览器不能覆盖恢复命令和目录。
- 原生查询：列表精确 workspace、recency 排序；正文搜索命中标题外内容，跨页过滤不漏行，有 cursor 的空页不代表无结果。
- 消息：使用命中轮次 cursor，过滤工具/reasoning，长消息和总页上限显式截断且保留命中。
- 兼容：不支持实验方法时返回 unsupported；Host/Origin/JSON 边界沿用。
- 页面：目录选择、Enter 搜索、高亮/定位、最近对话、独立恢复操作、窄屏返回、空结果/错误反馈。
- 回归：类型/语法、生产构建、全部后端/前端测试、相关文档扫描。
